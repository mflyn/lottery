# 最大熵融合推荐使用说明

在“号码推荐”页选择“融合推荐”，设置彩种和注数（1—100），点击“生成号码”。

- 历史期数默认 180；实际数据不足时使用已有记录，没有历史也能运行。
- 随机性 τ 默认 0.15。越大越接近均匀随机，越小越强调偏好；必须为正数。
- 种子可以留空，程序会生成并记录实际种子。固定历史、参数、种子和运行环境可复现结果。
- “高级权重”包含历史倾向、形态、去热门、历史新颖度、探索覆盖和近似重复六项。非负权重自动归一化，全部为零时使用精确均匀抽样。
- 历史硬过滤与最高评分候选池不作用于此策略；历史新颖度已经进入软成本。

结果优先展示随机参照百分位。点击“查看 F 与贡献明细”可展开组合偏好 F、分散程度 1−D，以及每注 H/T/C/R 和整组 E/D 的原值、有符号贡献。F 越大越符合所选偏好；τ 控制推荐随机性。

“按原快照复算”使用本次生成时保存的历史和配置，即使后来切换彩种或更新数据也不会改变它。“导出融合结果”支持：

- JSON：含完整历史快照、配置、实际随机种子、数据/配置哈希、算法版本、环境版本、每注解释、组合解释和采样诊断，适合保存与复现。
- Markdown：便于阅读的号码及解释报告；完整复现资料请同时保存 JSON。

生成期间可以点击“取消生成”；关闭窗口也会通知采样器停止。取消的结果不会作为完整推荐显示。

默认运行 4 条独立链，每条 max(5000, 200×注数) 步，其中前 max(1000, 50×注数) 步为预热。最终结果是等概率选取的一条链的最终状态，标为“有限步近似采样”。链诊断中的历史最高分只用于观察，不替代输出样本，不代表已经达到全局最优或已证明收敛。

遗漏以已经观察的开奖记录计算。快照内从未出现的号码，以及存在缺口/跨年完整性未确认的历史，保留截尾下界标记。

## Python 接口

```python
from src.core.generators.factory import create_generator
from src.core.generators.fusion.config import FusionConfig
from src.core.generators.fusion.history import FusionHistorySnapshot
from src.core.generators.fusion.result import FusionResult

config = FusionConfig(seed=20261103)
snapshot = FusionHistorySnapshot.from_data('ssq', history_dataframe, config.history_periods)
result = create_generator('fusion', 'ssq').generate_portfolio(10, snapshot, config)
numbers = result.numbers
portable_data = result.to_dict()
restored = FusionResult.from_dict(portable_data)
assert abs(restored.reevaluate()['F'] - result.score) < 1e-10
```

## 号码评价与候选搜索的统一评分

“号码评价”页使用同一套融合效用，默认历史范围 180 条，可编辑六项非负权重。单注按 K=1 评价，整注相似成本 D=0，其他五项正常计算，不重新分配 D 的权重。界面以随机参照百分位为主要显示，F 及各项原值、有符号贡献保留在默认折叠的详细信息中。负 F 值可以正常比较；比较时保持注数、历史范围和参数一致。

分析期数同时作用于评分、频率、遗漏与历史对比；“全部”使用所有已有记录。历史完整匹配会记录真实最大匹配数，未出现号码按观察记录数报告遗漏下界。

Markdown 报告展示融合解释与统计详情；选择 JSON 导出可以保存完整快照和配置，以 `FusionResult.from_dict(...).reevaluate()` 复算。修改界面参数、切换彩种或后续更新历史，不会改变已导出结果；多个评价任务重叠时只交付最新请求。

“最高评分（整注）”在候选池与原有形态筛选范围内，按同一个单注 F 精确排序，使用评价页的六项权重及所选历史范围。返回最多指定注数，同分按号码稳定排序；各注分数保留原始精度。它按单注排序，多注联动的覆盖与分散优化由“融合推荐”处理。

Python 评价接口的 `total_score` 字段现在是原始 F；`scores` 包含 H/T/C/R/E/D/total。旧的四项百分制分数和旧蓝球权重/遗漏曲线设置已经退出评分接口。使用自定义配置：

```python
from src.core.evaluators.ssq_evaluator import SSQNumberEvaluator
evaluation = SSQNumberEvaluator().evaluate(
    [1, 7, 12, 18, 25, 33], 8, periods=180, config=FusionConfig())
assert evaluation['scores']['D'] == 0
```

## 随机参照百分位（2026-11-04）

F 的计算保留，结果旁增加“F 严格超过约 X% 的随机参照组合”。比较条件是相同彩种、相同历史快照、相同 F 参数和相同注数 K：单注与随机单注比较，多注与同样 K 注的随机组比较。每个参照组内完整单注不重复，参照组之间独立抽样、允许重复。参照来自均匀合法空间，不使用筛选过的候选或融合采样结果作为基准。

默认抽取 N=2000 组，独立参照种子为 20261104。设当前 F 为 f，参照分数为 f_i，按浮点绝对容差 ε=1e-12 计数：

\[
\widehat P=100\times\frac{\#\{i:f_i<f-\varepsilon\}}{N}.
\]

同分比例单独显示；同分不算严格超过。全部权重为零时，所有 F 均为零，显示“超过 0%，持平 100%”。界面标明样本数及严格超过比例的 95% Wilson 抽样区间；例如“超过约 82%”描述与随机参照的相对位置，属于抽样估计。显示一位小数用于阅读，区间反映有限样本精度。

参照使用单独随机流，不消耗推荐采样器的随机数，因而不会改变相同生成种子下的推荐号码或 F。固定配置与种子复用缓存；温度、生成种子和采样步数不改变 F，也不会改变对应参照分布。不同历史、权重、形态参照或 K 使用各自的参照。

评价页、融合推荐、最高评分候选及 Markdown/JSON 报告均保存比较结果。JSON 的 `random_reference` 包含严格低分/同分/高分计数、N、种子、容差、95%区间、K、目标 F、历史/评分参数哈希和参照分布哈希。导出和展示直接读取保存结果。旧 JSON 未含该字段仍可导入；复算比较可调用 `compare_random_reference`。

首次计算在后台运行，显示“随机参照”进度，可以取消或关闭窗口。实测建立 2000 组参照的额外耗时：单注约 0.3—0.4 秒，10 注组约 1.9—2.3 秒，100 注组约 19—22 秒；同一参照缓存命中约小于 1 毫秒，实际耗时随环境变化。

```python
from src.core.generators.fusion.percentile import RandomReferenceConfig

# 参照配置独立于 F 配置；None 可跳过附加比较，F 不变。
evaluation = SSQNumberEvaluator().evaluate(
    [1, 7, 12, 18, 25, 33], 8,
    reference_config=RandomReferenceConfig(samples=2000, seed=20261104))
comparison = evaluation['fusion']['random_reference']
```

## 综合评价的显示顺序（2026-11-04）

评价结果卡片首先以大字号显示“约 X%”，下方说明这是“严格超过的随机参照比例”，并标明实际彩种、每组注数、样本量、持平比例和抽样区间。

“查看 F 与贡献明细”默认收起；展开后可查看原始 F 及 H/T/C/R/E/D 的原值和贡献。开始新评价或清空结果时，旧百分位和六项贡献会同时清空，详情恢复折叠。评价进行中或失败后展开详情，不会显示上一注的值。缺少随机参照的结果显示“--／随机参照未计算”，仍可展开查看 F。

融合推荐摘要按相同顺序呈现，默认隐藏 F 数值；完整 Markdown 报告在“评分详细信息”中保留 F、贡献和复现参数，JSON 字段保持原有完整数据。此调整仅改变展示，评分、排序和随机参照计算不变。

显示调整最终验证：完整桌面套件 495 项通过、0 失败、0 跳过、2 条既有警告，耗时 52.02 秒；其中真实窗口测试 48 项。回归覆盖默认折叠、展开/收起、缺少参照、重置及新请求进度/失败时旧贡献清空。历史数据文件哈希保持一致。
